# stock-autotrade-lab

한국주식(·미국주식·암호화폐) 자동매매를 연구하면서 만든 **투자 현황 대시보드와 백테스트 사이트**의 코드입니다.
누구나 사이트에 들어가 기술지표를 조합한 전략을 직접 백테스트해 볼 수 있습니다.

## 바로 해 보기

**사이트: http://34.64.211.150**
**아이디 `guest` / 비밀번호 `guest`**

1. 위 주소로 들어가 guest 로 로그인합니다.
2. 위쪽 메뉴에서 **백테스트**를 누릅니다.
3. 전략에서 **직접 만든 규칙 (기술지표 조합)** 을 고르고, 예시를 불러오거나 조건을 직접 만듭니다.
4. **백테스트 실행**을 누르면 KOSPI200 과 비교한 결과가 나옵니다.

> guest 로 돌린 백테스트의 설정과 결과는 저장되고, 사이트 운영자가 전략 연구에 참고할 수 있습니다.
> 성과가 좋은 설정(★)은 따로 모아 실제 운용에 쓸 만한지 검토합니다.
> 서버가 작아서 guest 는 IP마다 10분에 백테스트 20번, 검토 5번까지 실행할 수 있습니다.

## 백테스트로 할 수 있는 것

| 설정 | 고를 수 있는 것 |
|---|---|
| 매수 조건 (최대 6개, 모두 만족) | 이동평균 대비 가격, 이동평균 교차, 지수이동평균 교차, RSI, MACD 히스토그램, 볼린저 밴드 위치, n일 수익률(모멘텀), 변동성, 거래량 배수, n일 최고가 대비, n일 최저가 대비 |
| 종목 고르기 | 지표 순위 상위 N개 (높은 순·낮은 순) |
| 비중 | 동일 비중 또는 시가총액 비중, 종목당 최대 비중 |
| 리밸런싱 | 매일 · 매주 · 매월 |
| 시장 필터 | KOSPI200 이 n일 이동평균 위에 있을 때만 보유, 아니면 현금 |
| 섹터 과열 축소 | 위상적 데이터 분석(TDA)으로 계산한 섹터 과열점수가 높으면 비중을 줄임 |

준비된 예시: RSI 과매도 반등, 골든크로스 + 모멘텀, 신고가 근처 + 시장 필터, 볼린저 하단 매수, 저변동성, MACD 상승 전환 + 거래량.
그 밖에 시가총액 가중, 동일가중, 모멘텀 12-1, 이동평균 20/60 같은 기본 전략도 있습니다.

**계산 방식**

- 대상: 해마다 1월 첫 거래일 기준 KOSPI 시가총액 상위 30종목 (2011년 ~ 최근)
- 판단은 그날 종가까지의 정보로 하고, 매매는 **다음 날 시가**에 합니다. 미래 정보를 쓰지 않습니다.
- 수수료 0.015%, 매도세 0.20%, 슬리피지 0.05%, 정수 주문, 상·하한가(±30%) 체결 불가를 반영합니다.
- 결과는 수익률만이 아니라 **KOSPI200 대비**로 봅니다: 초과수익, 알파·베타, 정보비율, 상승장 포착률, 하락장 손실 비율, MDD 비율.

**저장과 검토**

- 실행한 백테스트는 자동으로 저장됩니다.
- 기간 3년 이상, 정보비율 0.3 이상, 하락장 손실 비율 0.9 이하, MDD 가 시장보다 크지 않으면 **★ 우수**로 표시됩니다.
- **검토** 버튼은 같은 전략을 해마다 쪼개 다시 돌려서, 한 해만 좋았던 것인지 여러 해에 걸쳐 시장을 이기는지 보고 "적용 후보 / 보류 / 부적합"을 판정합니다. 여러 번 시도해 가장 좋은 것만 고르면 우연히 좋아 보일 수 있다는 경고도 함께 나옵니다.

## 사이트의 다른 페이지

- **전체 현황**: 실전 투자(시작 전)와 모의투자 현황, 장중 5분 단위 자산 그래프
- **한국주식 · 미국주식 · 암호화폐**: 시장별 현황과 데이터 수집 상태, 최근 뉴스·SEC 공시
- **모의투자**: 한국투자증권 모의계좌 결과 (KOSPI200 대비)
- **투자 전략**: 지금 쓰는 전략과 실험으로 확인한 것

## 저장소 구성

```
stockrl/
  backtest.py      백테스트 (기술지표 11종, 직접 만든 규칙)
  env.py           매매 시뮬레이터 (체결·비용·가격제한·평가)
  baselines.py     기본 전략 (동일가중·모멘텀·이동평균 교차 등)
  metrics.py       성과 지표와 시장 대비 지표
  tda.py           섹터 과열점수 (지속 호몰로지)
  weights.py       비중 계산 (종목당 상한 재분배)
  web/             FastAPI 웹사이트 (화면·백테스트 저장·검토)
  glob/collect.py  미국주식·암호화폐 데이터·뉴스·SEC 공시 수집
config/train.yaml  시뮬레이터 설정
```

## 이 저장소에 없는 것

- 강화학습 모델(정책 신경망·학습·실험 코드)과 학습된 모델 파일
- 모의투자 매매 코드, 뉴스 신호, 증권사 API 연동 코드
- 수집한 데이터(가격 패널·DB)와 API 키

그래서 이 저장소만으로는 한국주식 백테스트를 로컬에서 그대로 돌릴 수 없습니다. 백테스트는 위 사이트에서 해 보세요.
미국주식·암호화폐 수집기(`stockrl/glob/collect.py`)는 혼자서도 동작합니다.

## 로컬에서 실행 (참고)

```bash
pip install -r requirements.txt
# 미국주식·암호화폐 데이터 수집 (SEC 공시는 .env 에 SEC_CONTACT=연락처이메일 필요)
python -m stockrl.glob.collect crypto-universe
python -m stockrl.glob.collect crypto-daily
python -m stockrl.glob.collect us-daily
# 웹사이트 (.env 에 WEB_PASSWORD 설정, 한국주식 백테스트는 data/processed/panel.npz 가 있어야 함)
uvicorn stockrl.web.app:app --port 8080
```

## 알림

이 사이트와 코드는 연구·학습용입니다. 투자 권유가 아니며, 백테스트 결과는 미래 수익을 보장하지 않습니다.
