투자 전략 설명

지금 쓰는 전략과, 실험으로 확인한 것 · 버린 것. 평가는 수익률만이 아니라 시장(KOSPI200) 흐름 대비로 한다.

1. 평가 기준

  • 시장 대비 초과수익, 알파·베타, 정보비율(초과수익의 꾸준함)
  • 상승장 포착률(시장 오를 때 따라간 비율)과 하락장 손실 비율(시장 내릴 때 같이 맞은 비율, 낮을수록 방어)
  • 1개월 단위 상승·하락·횡보장별 성과, 시장 대비 MDD
  • RL 모델 합격 기준(결과 보기 전 고정): 6개 구간 중 4개 이상 KOSPI200·동일가중을 둘 다 이김, 정보비율 ≥ 0.3, 하락장 손실 비율 ≤ 0.9, MDD ≤ 시장. 4개 모두 통과해야 장기몫을 RL 로 바꾼다

2. 한국주식 — 지금 운용 중 (모의)

장기몫 90%: 시가총액 가중

  • KOSPI 시가총액 상위 30종목을 상장주식수 × 현재가 비중으로, 종목당 최대 30%. 넘친 몫은 나머지에 비례로 나눔
  • 매일 09:01 리밸런싱, 목표와 차이가 자본의 1% 미만이면 거래 안 함(비용 절약)
  • 이유: 2021~2026 백테스트에서 동일가중은 대형 반도체 쏠림 장세에 KOSPI200 보다 크게 뒤짐 (2025 −39%p, 2026 −57%p). 시총가중 상한 30%는 −1~−7%p 로 시장을 거의 따라감

긴급 뉴스 몫 10%

  • 뉴스 감성(KR-FinBERT) + 언론사·기자 신뢰도 가중으로 강한 호재가 여러 언론사에서 동시에 나오면 건당 ≤3%, 하루 ≤3건 매수, 3거래일 뒤 청산
  • 악재 신호면 이 몫 보유분 매도
  • 과거 데이터로는 "언론사 2곳 이상 강한 호재" 매수가 다음날 시장 대비 −0.93% → 30%에서 10%로 줄이고 실제 체결로 검증 중

섹터 과열점수 (TDA) — 기록만

  • 섹터 구성종목 50일 점구름의 지속 호몰로지(H1) 크기를 과거 252일 백분위로 → 0.65 이상이면 과열
  • 과열 섹터 비중을 줄이는 방식은 모든 설정에서 손해(하락장 방어 +1%p 미만, 상승장 −50%p 안팎) → 지금은 매일 기록만 하고 다른 쓰임을 연구

리스크 관리

  • MDD 15% 넘으면 매수 중지, 하루 −5%면 그날 매매 중지, 주문당 자산의 30% 이하
  • 실전 주문은 별도 잠금(환경변수)을 풀어야만 나감

3. 연구 중

  • 강화학습(PPO, TCN+GRU+FiLM+Transformer): 지금까지 합격 모델 없음. 현금 많은 모델은 하락장 방어는 좋지만 상승장을 못 따라가고, 전액 투자 모델은 시장을 따라가지만 초과수익이 없음. KOSPI200 대비 보상·하락일 감점 실험 진행 중
  • 단타(장중): 분봉 가격·거래량 신호는 예측력은 있으나(IC 0.03~0.10) 왕복비용 약 0.35%(매도세 0.20% + 수수료 + 호가)를 못 넘음. 130종목(중소형주 포함) 분봉 1년치로 재시험 예정
  • 뉴스 직후 반응: 호재 뉴스는 이미 가격에 반영(오히려 시장보다 약함), 악재는 이후에도 약함 → 보유 종목 위험 신호로 활용 검토

4. 미국주식 · 암호화폐 — 계획

  • 같은 순서: 데이터 수집 → 장기 모델 + 단기 모델 → 모의/소액 검증 → 시장 대비 평가
  • 롱 + 숏, 레버리지(상한 2~3배부터), 청산가격·하루 손실 한도
  • 아주 작은 몫은 빠른 판단 API(jev·laya)에 가공한 데이터를 넘겨 판단 → 성과 보며 비율 조정
